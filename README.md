# talking-avatar

Story-neutral tool that turns a tagged script and a cast (voice provider + voice ID, portrait, an 8-shape mouth kit, one shared anchor) into lip-synced lines: `line.json` for live playback with `<SpeakingAvatar>`, or MP4.

Status: planning. See `docs/sdlc.md`, `docs/lip-sync-best-practices.md` and `plans/`.

Package manager: pnpm. `pnpm check` runs lint, typecheck, and tests. Releases of the workspace packages are published to npm. License: MIT.
